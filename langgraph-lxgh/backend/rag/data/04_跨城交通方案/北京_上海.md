# 北京↔上海交通方案对比

## 高铁

| 项目 | 信息 |
|------|------|
| **车程** | 约4.5小时（最快G开头列车4小时18分） |
| **班次频率** | 每天约40-50班，高峰时段每5-10分钟一班 |
| **票价** | 二等座553-626元，一等座882-1039元，商务座1748-1955元 |
| **出发站** | 北京南站 → 上海虹桥站 |
| **优点** | 准时、舒适、班次多、车站都在市区 |
| **缺点** | 票价较高，节假日票源紧张 |

## 飞机

| 项目 | 信息 |
|------|------|
| **飞行时间** | 约2-2.5小时 |
| **总耗时** | 4-5小时（含往返机场+安检+取行李各1小时） |
| **班次** | 每天约30-50班 |
| **票价** | 经济舱500-1200元（淡季），1200-2000元（旺季） |
| **出发** | 首都机场/大兴机场 → 虹桥机场/浦东机场 |
| **优点** | 长途最快，淡季常有特价票 |
| **缺点** | 机场远离市区、需提前到、受天气影响 |

## 自驾

| 项目 | 信息 |
|------|------|
| **总里程** | 约1200公里 |
| **耗时** | 约12-14小时（纯驾驶时间） |
| **过路费** | 约500-600元（ETC 95折） |
| **油费** | 约700-900元（普通家用车） |
| **路线** | G2京沪高速（全程）或G3京台高速 |
| **适合** | 2人以上出行、沿途自由停留 |
| **电车注意** | 需充电2-3次，总耗时增加2-3小时 |

## 综合推荐

| 场景 | 推荐方案 |
|------|---------|
| 单人出差 | 高铁二等座 |
| 多人出行 | 自驾（人均成本更低） |
| 紧急出差 | 飞机（总时间最短） |
| 预算有限 | 提前订高铁/关注特价机票 |
