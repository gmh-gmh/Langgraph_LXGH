# 北京↔广州交通方案对比

## 高铁

| 项目 | 信息 |
|------|------|
| **车程** | 约8-10小时 |
| **班次** | 每天约5-8班 |
| **票价** | 二等座862-966元，一等座1379-1550元 |
| **出发站** | 北京西站 → 广州南站 |
| **优点** | 直达、准点、全程有信号 |
| **缺点** | 耗时较长，坐一天较为疲惫 |

## 飞机

| 项目 | 信息 |
|------|------|
| **飞行时间** | 约3小时 |
| **总耗时** | 5-6小时（含机场往返+安检+取行李） |
| **班次** | 每天约15-20班 |
| **票价** | 经济舱600-1500元（淡季），1500-2500元（旺季） |
| **出发** | 首都机场/大兴机场 → 白云机场 |
| **优点** | 长途明显节省时间 |
| **缺点** | 机场远、受天气影响 |

## 自驾

| 项目 | 信息 |
|------|------|
| **总里程** | 约2100公里 |
| **耗时** | 约22-24小时（建议分2天驾驶） |
| **过路费** | 约900-1000元 |
| **油费** | 约1200-1500元 |
| **路线** | G4京港澳高速 |
| **中途休息** | 建议在武汉或长沙住宿一晚 |

## 综合推荐

| 场景 | 推荐方案 |
|------|---------|
| 所有情况 | **飞机**（距离太长，高铁/自驾都不舒适） |
| 预算优先 | 提前2周订机票 |
| 沿途办事 | 自驾分2天 |
