# 杭州↔上海交通方案对比

## 高铁

| 项目 | 信息 |
|------|------|
| **车程** | 约45分钟-1小时（最快46分钟） |
| **班次频率** | 每天100+班，每5-15分钟一班 |
| **票价** | 二等座73-87元，一等座117-139元 |
| **出发站** | 杭州东站 → 上海虹桥站（也有到上海站的班次） |
| **优点** | 班次极多、随到随走、比自驾还快 |
| **缺点** | 高峰期无座票较多 |

## 自驾

| 项目 | 信息 |
|------|------|
| **总里程** | 约175公里 |
| **耗时** | 约2-2.5小时 |
| **过路费** | 约70-80元 |
| **油费** | 约100-120元 |
| **路线** | G60沪昆高速 |
| **适合** | 多人出行、或需要上海用车 |

## 大巴

| 项目 | 信息 |
|------|------|
| **车程** | 约2.5-3小时 |
| **票价** | 约55-70元 |
| **班次** | 每天约10-15班 |
| **优点** | 价格最低 |
| **缺点** | 耗时久、舒适度一般 |

## 综合推荐

| 场景 | 推荐方案 |
|------|---------|
| 单人出行 | 高铁（最快最划算） |
| 2-3人带行李 | 自驾（人均成本接近高铁） |
| 省钱出行 | 大巴 |
