# 高峰时段市内交通省钱技巧

## 交通方式性价比排序

- **地铁**：时间最可控、性价比最高
- **公交**：最便宜，但受路况影响大
- **打车**：最贵但最灵活
- **共享单车**：短途接驳性价比之王

## 地铁省钱技巧

### 乘车码优惠
- 支付宝/微信乘车码常有随机立减
- 各城市地铁APP有月卡/周卡优惠
- 银联云闪付"62"开头的卡有优惠活动

### 换乘优惠
- 上海：公交地铁换乘立减1元
- 北京：地铁站外换乘公交有优惠
- 深圳：地铁公交换乘有0.4-0.6元减免
- 广州：公交地铁换乘立减1元

## 打车省钱技巧

### 平台选择
- 高德打车：聚合平台，可同时比价多个平台
- 滴滴：高峰期溢价严重，平峰较划算
- 花小猪：一口价模式，适合短途

### 省钱策略
- 平峰期打车比高峰期便宜30%-50%
- 提前叫车（预约）可能比即时叫车便宜
- 拼车比独享便宜30%-40%
- 使用优惠券（各平台月初发放）

## 自驾省钱技巧

### 加油
- 周二、周五部分加油站有会员优惠
- 使用团油、滴滴加油等APP比价
- 壳牌、中石化会员日有额外折扣

### 过路费
- 办理ETC享95折（全国通用）
- 节假日关注高速免费政策
